# HR Data Analysis

Exploratory data analysis on an HR employee dataset (316 employees, 36 features).

## What's covered
- Data Cleaning (dates, nulls, strings)
- Feature Engineering (Age, Tenure, Flags)
- Conditional Filtering
- Visualizations (Matplotlib & Seaborn)
